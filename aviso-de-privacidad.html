Aviso de Privacidad

KYPH es responsable del tratamiento de los datos personales que recaba directamente a través de sus canales digitales, comunicaciones, servicios e integraciones autorizadas.

1. Datos que podemos tratar

Dependiendo del servicio solicitado, podemos tratar datos como nombre, teléfono, correo electrónico, información de contacto, datos proporcionados durante una solicitud de asesoría y datos técnicos necesarios para operar integraciones autorizadas.

Integraciones con redes sociales

Cuando una persona autoriza una integración con una plataforma de terceros, KYPH puede recibir identificadores de cuenta, información básica del perfil necesaria para la autorización, permisos concedidos, tokens de acceso y actualización, así como información técnica relacionada con el envío, carga, publicación o estado de contenido. KYPH utiliza estos datos únicamente para ejecutar las funciones autorizadas.

2. Finalidades

  • Atender solicitudes de información, orientación o servicio.
  • Dar seguimiento a conversaciones, citas y procesos autorizados.
  • Operar herramientas digitales, automatizaciones e integraciones necesarias para prestar el servicio.
  • Preparar, cargar, publicar o consultar el estado de contenido en cuentas expresamente autorizadas.
  • Mantener seguridad, trazabilidad y registros operativos.
  • Cumplir obligaciones legales y responder solicitudes relacionadas con privacidad.

3. Datos de terceros y plataformas externas

Cuando utilizamos servicios de terceros, el tratamiento de datos también puede estar sujeto a las políticas y términos de dichos proveedores. KYPH procura solicitar únicamente los permisos necesarios para la función habilitada y no utiliza las credenciales personales del usuario fuera de los mecanismos oficiales de autorización.

4. Transferencias y encargados

Podemos utilizar proveedores tecnológicos para alojamiento, automatización, correo, almacenamiento, analítica, inteligencia artificial o redes sociales. Estos proveedores pueden procesar información únicamente para prestar los servicios contratados o autorizados. KYPH no vende datos personales a terceros.

5. Conservación

Los datos se conservan durante el tiempo necesario para prestar el servicio, mantener la trazabilidad requerida, cumplir obligaciones legales o atender solicitudes relacionadas con la cuenta. Los tokens o permisos de plataformas externas podrán revocarse cuando dejen de ser necesarios o cuando el usuario retire su autorización.

6. Seguridad

Aplicamos medidas razonables de seguridad para limitar accesos no autorizados. No solicitamos contraseñas de redes sociales por correo, mensajería o formularios de contacto.

7. Derechos de acceso, rectificación, cancelación y oposición

Para ejercer derechos relacionados con tus datos personales, solicitar información, revocar una autorización o pedir la eliminación de datos bajo nuestro control, escribe a david@kyphseguros.com. La solicitud deberá incluir información suficiente para identificar al titular y la petición que desea realizar.

8. Revocación de integraciones

Los usuarios pueden revocar permisos directamente desde la configuración de la plataforma externa correspondiente. También pueden solicitar a KYPH que deje de utilizar una integración y elimine los tokens bajo nuestro control, cuando resulte aplicable.

9. Menores de edad

Los servicios e integraciones descritos en este sitio están dirigidos a personas adultas. No buscamos recopilar intencionalmente datos de menores mediante las integraciones descritas.

10. Cambios a este aviso

Podemos actualizar este aviso cuando cambien nuestros servicios, integraciones o requisitos legales. La versión vigente se publicará en esta misma dirección.

Este documento es una base operativa para el sitio y las integraciones de KYPH. Antes de utilizarlo como aviso integral para capturar datos financieros, patrimoniales o sensibles, debe revisarse jurídicamente y ajustarse a los tratamientos reales de KYPH.
